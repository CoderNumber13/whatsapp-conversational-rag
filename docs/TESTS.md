- **Permissive hands more evidence to the model**
- **An explicit top n still overrides the profile**
- **Strictness reaches the rerank stage too** — The rerank depth must follow the profile, not stay at the default.
- **No mode introduces a retrieval score threshold** — Every mode must still disable the cosine gate entirely.
- **Min retrieval score is never compared to a fused or reranked score** — The cosine floor stays a cosine floor. If a mode ever passed it into the stack, RRF values (~0.03) and cross-encoder logits (mostly negative) would fall below 0.25 and abstain on everything.

- **App defaults to balanced**
- **App still exposes no score threshold**
